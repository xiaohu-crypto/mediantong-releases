Architecture

1. 全局与技术约束

本地优先的个人桌面工作台,服务媒体广告从业者"获客—策略—执行—复盘—成长"全流程。所有外部操作(AI 调用/云备份/导入导出)需用户显式授权。

层面选型约束
应用壳Electron(托盘/全局快捷键/通知/自更新)P0 定案;二期可评估 Tauri 瘦身,架构上壳与业务分层解耦
前端React 18 + TypeScript 严格模式组件库按第 3/4 章自建,禁止引入与设计系统冲突的 UI 库
样式CSS 变量(设计令牌)+ CSS Modules禁止硬编码色值/字号/圆角;令牌见 3.2

非结构化本地文件系统按 2.2 目录组织;文件登记指纹(hash)支持完整性扫描

文档解析PDF/Word/Excel/PPT 解析库 + .emlExcel 导入走"列名 AI 匹配→预览→批量导入→查重合并"

1.2 六层架构

  1. 表现层 — 今日驾驶舱 + 八大模块页面(布局范式见 4.1)
  2. 业务模块层 — 八大业务逻辑
  3. 系统服务层 — 统一搜索/通知提醒/自动化工作流/标签治理/模板管理/文件管理/校验引擎/操作日志
  4. 数据处理层 — 信息采集管线 + 文档导入引擎 + 数据校验 + 脱敏代理
  5. 数据存储层 — IndexedDB(带版本迁移)+ 文件系统(带指纹登记)双轨
  6. 集成对接层 — 微信(粘贴/文件导入)/邮件(.eml,默认关闭)/OCR/浏览器剪藏/AI(本地+云)

Data Model

2. 数据存储与核心数据模型

本章修复 v1.0 的三处主数据冲突,并补齐媒体行业缺失实体。实体字段为最小必集,开发可扩展但不得删减;枚举值见各表,自定义字段机制见 2.4。

2.1 存储规范与演进

  • 双轨存储:IndexedDB(结构化)+ 文件系统(非结构化),与 v1.0 一致;目录结构沿用 v1.0 §3.2(客户/项目/知识库/备份/附件归档)。
  • schema 版本迁移:每个对象仓库存 schemaVersion;升级走幂等迁移脚本,失败可回退;迁移在验收中单独测(造 v1 数据→升级→字段无损)。
  • 引用完整性:删除客户时关联实体(商机/合同/回款/任务/文件引用)默认阻止删除并提示,可选"归档";全部删除走软删除 + 回收站(30 天),回收站可恢复。
  • 操作日志与回滚:所有写入记录 who/what/when + 回滚载荷(变更前快照),单条变更支持撤销;批量操作支持"就地撤销"(Toast 内 Undo)。
  • 文件一致性:文件入库登记指纹(大小+hash);提供"完整性扫描",悬空引用可修复或重链。
  • 导入幂等与查重:名片 OCR / Excel / 微信记录导入统一查重键(手机号 > 微信号 > 名称相似度),命中多客户时出人工确认 UI。

2.4 校验引擎与扩展机制

  • 校验规则(沿用 v1.0 §3.3):客户名称同级必填唯一;手机号 11 位 1 开头;金额 >0 两位小数;阶段/等级/角色必须来自枚举白名单。
  • 标签分层治理(R1 定案):系统枚举(阶段/等级/角色)严格白名单;用户标签允许自由创建,提供合并/别名/颜色管理;跨模块标签统一存储。
  • 自定义字段(R2 定案):客户/商机支持用户自定义字段(文本/数字/日期/单选),字段定义存元数据表;自定义阶段:允许在默认阶段间插入自定义阶段,不可删除系统阶段。
Design System V2

3. 视觉系统(抖音主题色 + 媒电通图标)

深色默认、浅色辅助。对标国内成熟产品形态(飞书/纷享销客/探迹/语雀),视觉语言为"层次黑工作台 + 抖音双色强调 + 媒电通图标"。参考原型:V2 媒体广告工作台-UI原型图.html。

3.2 图标系统(媒电通 VI,已冻结)

  • 24×24 视口 · 1.6px 描边 · 圆头圆角(stroke-linecap/join: round);SVG sprite,命名 icon-*(icon-home/icon-create/icon-material/icon-chart/icon-funnel/icon-wallet/icon-search/icon-plus/icon-bell/icon-trash 等全套 38 枚,以《媒电通图标VI》PDF 为准)。
  • 默认色 #E8E8EC(跟随文字);激活/强调唯一彩 = 品牌红;禁用 35% 不透明度。
  • 尺寸阶梯:20px 密集 / 24px 基准 / 28px 大;触控目标 ≥ 44px。
  • 浅色主题下图标默认色反向跟随文字(#3A3D44)。禁止 emoji 作为任何 UI 元素。

3.3 字体与排版

  • 中文:思源黑体 / HarmonyOS Sans / MiSans(三选一,商用授权核查后冻结);西文:Inter;代码/数字:JetBrains Mono。
  • 金额与指标一律 tabular-nums 等宽数字;金额单位系统化(元/万元)。
  • 字号阶:12/13/14/16/18/20/24/30(沿用 v1.0 §4.1);间距 4px 基准 8 级(v1.0 "13 级"表述作废,以 8 个令牌为准);圆角 4/6/8/12/999;动效 150ms 反馈 / 300ms 过渡,尊重 reduced-motion。

3.4 主题与品牌触点(双轨制)

工作界面(克制轨):中性黑灰白 + 表格数字排版,红色只出现在激活态与关键行动。禁止大面积玻璃拟态/霓虹渐变。
品牌高光面(释放轨):启动屏、月度成绩单、导出报告封面、提案模板封面、空状态插画——允许红青双色与创意表达。
  • 专注模式(R4 定案):快捷键或顶栏触发,侧栏收窄为图标条、品牌强调色灰化,保留纯内容视图。
  • 明暗双主题:全部令牌双份,主题切换无需重启;图表在两主题下分别校验对比度。
Interaction

4. 交互规范

三栏工作台范式 + 命令面板 + 抽屉详情。参考 V2 原型交互:列表点行开抽屉、Ctrl+K 快速采集、专注模式切换。

4.1 布局与导航

  • 三栏范式:左侧导航 236px(可收窄为 56px 图标条)/ 中部列表或看板 / 详情走右侧抽屉 460px(R4 定案,不再用并排三栏详情)。

5.1 CRM 客户管理 修订

  • 比稿(Pitch)管理(R2):记录投入(工时/成本)、竞对、结果、败稿复盘;比稿成功率进预测模型与月度成绩单。

  • Next-Best-Action:并入本模块 Agent——"今天最该联系谁"排序卡(沉默天数×价值×阶段)+ 一键生成跟进话术草稿(带知识库溯源)。

5.3 媒介策略中心 修订 新增采购链

  • 三层架构沿用(策略/执行/评估)。
  • 供应商主数据:MediaSupplier(官方/代理/达人机构)+ 返点政策;MediaBuy 必关联供应商。

5.4 数据分析报表 修订 新增基准
