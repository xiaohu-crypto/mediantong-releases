七、踩坑与约定(新会话必读)

  • 执行方式:原生工具直接实现(本会话全程验证有效);小步:typecheck→test→build→commit→push。
  • PowerShell 写文件:中文/代码一律 [System.IO.File]::WriteAllText(path, text, UTF8Encoding($false));多行锚点必须行级 splice 或动态探测 $nl(文件 CRLF/LF 混杂是常态);大改用 ReadAllLines+RemoveRange/InsertRange。
  • idb 大坑:upgrade 回调不会 await async,且 versionchange 事务在 await 非 IDB 异步(WebCrypto/IPC)时自动提交 → 数据迁移必须放开库后独立执行(encryptPlaintextLegacy 模式,幂等标记+__enc 跳过)。
  • E2E 纪律:每用例独立 --user-data-dir;交互用 dispatchEvent("click")(桌面被占用时坐标点击/稳定性检查不可靠);launch 后 show+focus+setAlwaysOnTop+setBackgroundThrottling(false),args 带 occlusion/节流开关;断言避免 text= 子串歧义(如「导入完成」撞「撤销本次导入完成」)。
  • git:add -A 前确认 .gitignore 覆盖 debug 产物;提交人 xiaohu-crypto;push 直接推。
  • 安全门:含删除动作的脚本会触发审批,探测/诊断脚本禁带 rm;被拒后本轮不重试同操作。
  • 诚实纪律:GUI 行为没实测就说没实测;验收状态只按证据升级;密钥不落盘不进日志。
