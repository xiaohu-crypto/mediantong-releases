三、已冻结的技术与设计定案(勿推翻)

  • 平台:Electron 桌面壳 + Web 技术栈(React 18 + TS strict + Vite + vitest);托盘/全局快捷键 Ctrl+K/通知/开机自启已实现。
  • 存储:IndexedDB(schemaVersion=2 幂等迁移,21 个仓)+ 本地文件;软删除回收站 30 天;操作日志含 before 快照可撤销。
  • AI 路由:敏感数据默认本地;云调用强制过脱敏代理(手机号/金额/税号/客户名→占位符→还原);输出带 云/本地 徽标 + 路由原因;确认门槛低/中/高三级。
  • 云模型:Agnes AI,Base URL https://apihub.agnes-ai.com/v1,默认模型 agnes-2.5-flash,OpenAI 兼容(官方文档 wiki.agnes-ai.com)。
  • 密钥安全:绝不写入源码;Electron safeStorage 加密存本地库;浏览器模式回退明文并标示。
  • 色彩纪律:品牌红 #FE2C55 仅激活态/主CTA/红点,禁止表达错误(危险用 #FF6B6E);图表主系列青 #25F4EE;深色默认浅色辅助;专注模式;源码禁 emoji、禁硬编码色值(仅 tokens.css)。
  • 主数据:Deal 唯一漏斗;Contact 一级实体;Payment/RateCard 版本/Pitch/Expense 等实体见需求文档 2.2;口径表见 2.3(健康度权重 30/30/20/20、冷启动 70)。
  • 收件箱已废弃:采集走「快速采集」弹层(Ctrl+K),邮件渠道默认关闭。
  • 对标国内产品(飞书/纷享销客/探迹/语雀),不做抖音生态化;媒电通 VI 只用图标与品牌红。
